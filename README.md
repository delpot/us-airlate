# US AirLate - Interactive Flight Delay Insights

Interactive visualization of US flight delays and disruptions, built with D3.js.

MIAGE M2 MBDS data visualization project.

> **Work in progress**

## Goal

Explore how delays evolve over time, how they differ across airports, airlines and routes, and which factors are linked to disruptions.

## Data

- [US Flight Delays 2025 (BTS On-Time Performance)](https://www.kaggle.com/datasets/a7madmostafa/us-flight-delays-2025-bts-on-time-performance)
- [Flight Delay Dataset — 2024](https://www.kaggle.com/datasets/hrishitpatil/flight-data-2024)

Raw data is not included in this repository.
